# 📖 Руководство по стилям и разметке Вики (Wiki Styleguide)

Все страницы вики размещаются в директории `src/pages/wiki/*.astro` и используют базовый макет `Layout.astro`, глобальный файл стилей `src/styles/wiki.css` и компонент оглавления `TableOfContents.astro`.

---

## 🚀 Базовый шаблон новой статьи

```astro
---
import Layout from '../../layouts/Layout.astro';
import TableOfContents from '../../components/TableOfContents.astro';
import '../../styles/wiki.css';
---

<Layout title="Название статьи — Проект MAID">
  <main class="wiki-container">
    <!-- Хлебные крошки -->
    <nav class="breadcrumbs">
      <a href="/">Главная</a>
      <span class="sep">/</span>
      <a href="/wiki">Вики</a>
      <span class="sep">/</span>
      <span class="current">Название</span>
    </nav>

    <!-- Шапка статьи -->
    <header class="wiki-header">
      <div class="header-tag">Категория</div>
      <h1 class="wiki-title">Название статьи</h1>
      <p class="wiki-subtitle">Краткое резюме того, о чем статья.</p>
    </header>

    <!-- Введение + Fandom TOC (в одну строку на десктопе) -->
    <div class="wiki-lead-wrapper">
      <div class="intro-block">
        <p>Главный вступительный текст статьи...</p>
      </div>
      <TableOfContents />
    </div>

    <!-- Основной контент статьи -->
    <article class="wiki-content">
      <section class="section-card">
        <h2 id="section-1">Раздел 1</h2>
        <p>Текст раздела...</p>
      </section>
    </article>
  </main>
</Layout>
```
```md
1. Каркас и верстка

.wiki-container — главный контейнер статьи. Не имеет жесткой ширины (адаптируется под 80% от Layout.astro).
.wiki-lead-wrapper — flexbox-ряд (direction: row) для одновременного показа intro-block и оглавления. На экранах <= 768px автоматически переходит в колонку (direction: column).
.intro-block — стильная вводная карточка статьи с увеличенным интерлиньяжем.
.section-card — стандартная карточка для раздела (<h2>). Имеет темный полупрозрачный фон, границу с неоновым оттенком и плавную подсветку при наведении.
.sub-block — блок подразделов с пунктирной линией сверху.

2. Заголовки и оглавление

.header-tag — неоновый бейдж категории над заголовком статьи (Регламент, Лор, Безопасность).
<TableOfContents /> — компонент оглавления. Автоматически находит все <h2> и вложенные в них <h3>.
Рядом с <h2> появляется стрелочка ▾, которая позволяет сворачивать и разворачивать подпункты h3.
Ограничен по высоте скроллбаром (max-height: 440px), не занимает весь экран.

3. Баннеры и плашки

.age-banner — аварийный красно-оранжевый баннер возрастного ограничения (16+).
.priority-banner — официальный баннер NanoTrasen (с логотипом слева и текстом справа).
.callout .callout-warning — блок важного примечания/предупреждения с иконкой ⚡.

4. Списки

.styled-list — маркированный список с правильными отступами.
.styled-numbered-list — нумерованный список.

5. Таблицы

Любая таблица оборачивается в .table-scroll для горизонтальной прокрутки на смартфонах.
.matrix-table — матрица быстрого поиска (например, Космического Закона).
.data-table — стандартная таблица с темными заголовками и белым текстом.
.law-table — таблица описания законов. Картинки внутри .law-table img имеют размер 128px и плавно увеличиваются в 1.65 раза при наведении курсора.
Степени тяжести нарушений (применяются к ячейкам или строкам):
.row-sev-1 / .cell-sev-1 — малые (зеленый)
.row-sev-2 / .cell-sev-2 — легкие (золотой)
.row-sev-3 / .cell-sev-3 — средние (янтарный)
.row-sev-4 / .cell-sev-4 — тяжкие (оранжевый)
.row-sev-5 / .cell-sev-5 — особо тяжкие (красный)
.row-sev-6 / .cell-sev-6 — критические (темный / void)

6. Сетки и карточки сущностей

.cards-grid — отзывчивая CSS Grid сетка (minmax(280px, 1fr)).
.entity-card — карточка расы, существа или технологии.
.entity-badge — бейдж внутри карточки.
.danger-card / .badge-danger — красная карточка для опасных врагов (например, Генокрады).

7. Хронология (Timeline)

.timeline — вертикальная линия шкалы времени.
.timeline-item — событие со световой точкой.
.timeline-highlight — ключевое событие с неоновой подсветкой точки.
.timeline-current — зеленая точка текущего года.

8. Достоинства и недостатки

.pros-cons-grid — двухколоночная сетка.
.pro-box — блок плюсов (зеленая рамка).
.con-box — блок минусов (красная рамка).
```
